Final Project: BeautifulSoup Documentation Analytics System¶

Team Project - Course: PDS301m (Python for Data Science)

Project Goal: Build an end-to-end data pipeline to collect, parse, extract, and analyze structural metadata from the official BeautifulSoup documentation page (Feature 6 Focus).

Target URL: https://www.crummy.com/software/BeautifulSoup/bs4/doc/

Project Architecture¶

The core logic lives in the src/ Python package, allowing both scripts and interactive notebooks to run the same code:

File Component Description
src/collector.py Feature 1: Web Page Collector Downloads and saves raw HTML
src/parser.py Feature 2: HTML Parser Parses HTML with BeautifulSoup
src/extractor.py Features 3, 4, 5: Data Extractors Extracts Sections, Links, and Code Examples to CSVs
src/analyzer.py Feature 6: Doc Analytics Answers 8 required and 2 additional analytics questions
src/visualizer.py Feature 7: Data Visualization Generates 4 charts saved to output/charts/
src/report_generator.py Feature 8: Final Report Generates Markdown & HTML report in output/
src/main.py Orchestration Pipeline Runs the entire pipeline sequentially (Features 1-8)

The cells below walk through the entire pipeline step-by-step.
